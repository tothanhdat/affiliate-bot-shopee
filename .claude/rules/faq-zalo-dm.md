# FAQ tự trả lời trong Zalo DM (src/core/faq/)

> Đọc khi sửa `src/core/faq/*`, thêm chủ đề FAQ, đổi nhà cung cấp LLM, hoặc sửa hành vi im lặng/escalate.

**faq/** — (2026-09-13) FAQ tu dong tra loi cau hoi co che chung trong ZALO DM (khong lam trong group, khong lam Telegram). LLM **CHI PHAN LOAI** cau hoi vao 1 trong 8 chu de co dinh (faqTopics.ts), text gui user LUON la chuoi admin soan san (sua qua /admin/settings, key `faq_answer_<id>` sinh boi faqAnswerKey()) - day la ly do bot KHONG THE bia thong tin ve tien, doi lai khong tra loi duoc cau ngoai kich ban (co chu dich: cau ngoai kich ban -> im + bao admin). faqService.ts dieu phoi: **cau hoi rong -> im** -> mute -> rate limit -> classify -> render placeholder; tra `null` = IM LANG (moi quyet dinh im/noi nam o day, adapter khong tu suy luan). Cua **cau hoi rong** them 2026-10-01 tu bug that: khach CHAP NHAN loi moi ket ban thi Zalo day vao thread DM mot tin nhan NOI DUNG RONG, chuoi rong di toi classifier -> Anthropic tra 400 ("user messages must have non-empty content") -> nhanh catch coi nhu "khong nhan ra chu de" -> bot gui cau "ngoai pham vi" cho nguoi CHUA HE HOI GI. Chan o CA 2 lop (zalo/bot.ts chan tu goc + chot nay), co test chan ca hai.

**Classifier LOI (het han muc/500/mang/401 key het han) KHAC HAN "chay xong ma khong khop chu de nao"** (2026-10-01, yeu cau truc tiep cua user - truoc do 2 nhanh bi GOP): loi -> `return null` IM LANG voi khach + bao admin bang tin RIENG co "⚠️" kem ca cau hoi lan ly do loi (escalateClassifierFailure, khac tin "cau hoi khong hieu" cua escalateToAdmin - admin doc 1 dong phai biet la di sua API hay di soan cau tra loi moi, co test chan viec dung chung cau). Ly do: luc API sap bot CHUA HE doc duoc cau hoi, noi "cau hoi nay ngoai pham vi" la noi SAI voi khach. Danh doi da chap nhan: API sap thi MOI tin DM sinh 1 thong bao admin, va khach khong nhan duoc gi nen admin PHAI doc thong bao de tra loi tay. Cau "ngoai pham vi" tu gio CHI gui khi classifier da doc xong va that su khong khop chu de nao. faqClassifier.ts la interface -> doi nha cung cap LLM khong dung logic; **khong doc duoc cau hoi thi implementation phai THROW, dung tra mang rong**. providers/index.ts chon theo FAQ_PROVIDER (off|claude), **MAC DINH off**; **factory tra `null` khi FAQ khong chay duoc** (provider khac "claude", hoac thieu apiKey - kem canh bao chu khong throw) va index.ts KHONG tao FaqService khi do, nen adapter im lang tuyet doi qua duong `faqService === undefined` da co san (co test chan o zaloBot.test.ts + faqProviders.test.ts).

**Truoc 2026-10-01 factory tra OffFaqClassifier voi classify() -> mang rong, ma mang rong lai roi dung vao nhanh "khong nhan ra chu de" nen bot tra "Cau hoi nay ngoai pham vi..." cho MOI tin DM tren moi instance de FAQ_PROVIDER=off** - trai han voi loi hua "chua set ANTHROPIC_API_KEY thi hanh vi bot khong doi mot ly nao". Class OffFaqClassifier da bi XOA, dung tao lai. providers/claudeClassifier.ts goi claude-haiku-4-5, doc response text thuan roi loc qua parseTopicIds() - CHI chap nhan id CO THAT trong FAQ_TOPICS va tra RONG neu model tra ve qua 2 id (dau hieu doc vet ca danh sach thay vi chon). Bang faq_thread_mutes trong ledgerStore luu thread dang bi khoa (muted_until NULL = vo thoi han).
