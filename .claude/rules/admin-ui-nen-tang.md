# Admin UI — nền tảng: Tailwind, adminShell, thành phần dùng chung

> Đọc TRƯỚC KHI sửa giao diện bất kỳ trang `/admin/*`: 4 cái bẫy đã dính thật của Tailwind không-preflight nằm ở đây.

## styles/admin.css + adminAssets.ts (4 cái bẫy)

src/api/styles/admin.css + adminAssets.ts  **(2026-10-04) Tailwind v4 cho khu /admin.** Nguon CSS build ra `public/admin.css` qua `npm run build:css` (da nam trong `npm run build` va `npm run dev`; `public/` DA .gitignore vi la san pham build nhu `dist/`), serve boi `app.use("/admin/assets", express.static(...))`.

**KHONG NAP PREFLIGHT** - co chu dich va la quyet dinh quan trong nhat cua file do: chi `@import "tailwindcss/theme.css"` + `utilities.css`, khong `@import "tailwindcss"`. Ly do: preflight doi hinh MOI trang cung luc (h2 mat font-weight dam, p mat margin, control ve kieu tran) ma 5 trang kia van dung CSS tay trong `shellStyles()`.

**He qua phai nho: control nao dung trong markup moi thi TU reset du vien/nen/font** - da dinh that mot lan, nut copy ma don hien ra thanh o vuong xam vi `<button>` giu nguyen vien+nen mac dinh cua trinh duyet.

**Bay thu hai da dinh: CSS trong the `<style>` cua `shellStyles()` KHONG nam trong @layer nao, ma CSS khong layer thi THANG moi CSS co layer** bat ke do dac hieu - nen `thead th { padding }` toan cuc de bep `class="px-4 py-3.5"` cua Tailwind (class co trong DOM ma khong tac dung). Da khoanh 4 selector bang cu thanh `.card table` / `.card thead th` / `.card tbody td` / `.card tbody tr:last-child td`; **moi bang cua 5 trang chua lam lai deu nam trong `.card`, them bang moi vao trang cu thi PHAI de trong `.card`**. `adminCssHref()` gan "van" theo mtime cua file da build vao URL (`?v=...`) nen cache dai + `immutable` van an toan - thieu no thi sau moi lan deploy admin dung CSS CU den khi cache het han (da gap that luc preview). Thieu `public/admin.css` thi KHONG crash: `adminCssHref()` lui ve `?v=dev` va `createServer()` in canh bao chi ro phai chay lenh nao.

**Bay thu BA da dinh, nghiem trong nhat (2026-10-04): class Tailwind tuy y chua KHOANG TRANG bi bo quet @source cat token va KHONG SINH RA CSS NAO, khong co loi build nao bao.** `SELECT_CHEVRON_CLASS` tung la `bg-[url('data:image/svg+xml;utf8,<svg xmlns=%22...%22 viewBox=%220 0 24 24%22 ...')]` - chuoi SVG co dau cach that (vd `viewBox=%220 0 24 24%22`), ma Tailwind v4 scan source bang tokenizer tach theo KHOANG TRANG, nen no chi doc duoc phan truoc dau cach dau tien roi bo qua vi ngoac vuong chua dong (khong hop le) - TUYET DOI khong co dong canh bao nao luc `npm run build:css`, mui ten dropdown tren CA 4 <select> cua 3 trang (orders/users/record-orders) am tham bien mat tu lan dau tien va chi bi phat hien khi nhin man hinh that.

**Sua bang doi sang 1 class CSS viet tay** (`.field-select` trong `admin.css`, @layer components) thay vi utility tuy y - `SELECT_CHEVRON_CLASS` gio chi la chuoi `"field-select"`.

**Quy tac rut ra: bat ky gia tri nao co the chua khoang trang (SVG data-URI, chuoi JSON, URL nhieu tham so) thi KHONG duoc dua vao `bg-[...]` hay bat ky utility tuy y nao cua Tailwind - phai viet thanh class CSS that trong admin.css.** Sau khi them 1 utility tuy y moi, grep lai `public/admin.css` de xac nhan no that su duoc sinh ra - dung tin typecheck/test, ca hai deu khong bat duoc loai loi nay vi day la loi o tang build CSS.

**Bay thu TU da dinh (2026-10-05, /admin/settings): dat thuoc tinh `.hidden = true` (JS) tren mot phan tu VON CO class `flex`/`grid`/`block`/... KHONG an duoc gi ca tren trinh duyet that, du `el.hidden` doc lai van tra `true`.** Nguyen nhan: khong nap preflight nen khong co rule `[hidden]{display:none}` cua UA stylesheet du manh - CSS cascade xet ORIGIN truoc SPECIFICITY (author luon thang UA bat ke do dac hieu), ma `.flex{display:flex}` cua Tailwind nam trong `admin.css` (author stylesheet) nen LUON thang thuoc tinh `hidden` cua UA, bat ke class nao khai bao truoc/sau. Phat hien that: nut "Luu cau hinh"/"Luu tat ca thay doi" cua `renderSettingsPage()` van hien nguyen tren tab "Thong bao nhom Zalo" du script da chay `topBar.hidden = true` dung luc - `getComputedStyle(el).display` van tra `"flex"` (da verify tay bang DevTools).

**Sua bang ham `setHidden(el, hide)` set THANG `el.style.display = hide ? "none" : ""`** - inline style luon thang moi class du co "flex" hay khong, khong phu thuoc thu tu CSS. Chi can sua cho phan tu NAO VON co class dat `display` (topBar/bottomBar/dirtyBar cua trang settings co class `flex`); phan tu khong co class dat display (vd `<tr>` chi co `class="transition hover:bg-slate-50/80"`, hay `<div data-panel>` khong co class nao) thi `.hidden` van hoat dong dung - KHONG can sua dong loat moi cho dung `.hidden =` trong adminHtml.ts, chi cho nao co class flex/grid/block canh tranh.

**Bay nay node:vm khong bat duoc**: test DOM gia (`settingsPageScript.test.ts`) chi gan/doc property JS thuan, khong co CSS cascade that nen se "xanh gia" voi ca ban loi lan ban sua - phai verify bang trinh duyet that (`getComputedStyle`) nhu 2 bay truoc. Test hien tai chi chan REGRESSION (grep script khong duoc quay lai `topBar.hidden =`), khong tu phat hien lai duoc loai bug nay neu no xuat hien o cho khac.

## Giao diện thẻ KPI

**Giao dien the KPI (2026-10-01, theo anh tham chieu cua user)**: nhan nhom la 1 CHIP nam TRONG the, goc tren ben PHAI (.kpi-top chua nhan ben trai + .kpi-chip ben phai). Da thu phuong an chip lam tieu de rieng cho ca nhom va BO: tren man hep (luoi ve 1 cot) moi chip an tron mot hang, ton dien tich hon la tiet kiem. Chip co flex-shrink 0 + white-space nowrap de khong vo thanh 2 dong lam lech chieu cao cac the cung hang; nhan the moi la thu duoc phep xuong dong (vd the "Chờ duyệt rút" o man hep: nhan + chip tren mot dong, badge "Cần xử lý" tut xuong dong duoi). Ca 4 chip dung MAU TRUNG TINH, chi khac icon (rieng the alert doi chip sang tong do cho khoi lac loai tren nen do nhat) - co chu dich, to mau theo nhom se lan voi mau DU LIEU trong chart (cam = "Chờ xác nhận"/"Lợi nhuận chủ bot", xanh la = "Khả dụng") va lam mau mat nghia. The co hover (vien tim + nhac len 2px + do do); rieng the alert giu vien DO khi hover (dang bao co viec phai lam, khong duoc doi sang tim); chart-card hover KHONG nhac len vi canvas ve lai theo pixel se nhoe chu truc trong luc chuyen. Trang van la theme SANG - khong chuyen rieng trang nay sang toi vi 5 trang /admin con lai deu sang, doi mot trang se lech khi di chuyen qua lai.
