## Công thức lợi nhuận chủ bot

(2026-10-10, yeu cau truc tiep cua user)

**The "Loi nhuan chu bot" o /admin/dashboard doi cong thuc: KHONG tru phi 1%.** Loi nhuan = `commission_amount - tax_amount - user_share_amount` (hang so `OWNER_PROFIT_SQL` trong ledgerStore.ts), khong con la `after_tax_amount - user_share_amount`. Ly do cua user: 1% (`platformFeePercent`) la khoan CHU BOT TU nghi ra de thu them cua user bu chi phi van hanh, khong phai phi Shopee/san - nen no nam LAI trong loi nhuan chu khong bi tru. Them so phu **"truoc thue"** = `commission_amount - user_share_amount` (`ownerProfitBeforeTax`, `OWNER_PROFIT_BEFORE_TAX_SQL`) hien BEN CANH so chinh, font nho hon (`.kpi-value-row` / `.kpi-value-sub`; so phu nam NGOAI `.kpi-value` vi test lam tron so le doc regex tren `kpi-value`). Duong "Loi nhuan chu bot" cua chart hoa hong theo ngay (`sumCommissionByDay`) doi CUNG cong thuc - 2 cho cung ten khong duoc lech nhau (co test: tong cac ngay = so tren the). Hint cua the KHONG hardcode "1%" vi ty le la setting.

**/admin/orders (cung ngay, yeu cau user "chi chinh o THE, khong chinh o COT")**: the KPI "Loi nhuan chu bot" (`getOrdersFilterTotals().ownerShareTotal`) doi CUNG cong thuc + them so phu "truoc thue" (`ownerShareBeforeTaxTotal`, qua tham so `sub` moi cua `kpiCard()` - khong truyen thi layout y het cu), nhung COT "Chu bot nhan" trong bang VAN la `after_tax_amount - user_share_amount` (da tru phi) - co chu dich, co test chan.

**He qua da biet va user chap nhan: tong cot "Chu bot nhan" tren trang se NHO HON the dung bang tong phi 1% cua cac don do** (2 con so khong cong khop nhau); dung "sua lai cho khop" khi user chua yeu cau. `computeCommissionBreakdown().botShareAmount` cung giu nguyen (= phan con lai sau phi), khong dung cho 2 the nay.
